Focus on the exact reported failure. Keep signatures, registered state, training,

Your context is this delegated prompt string, not the root task dictionary.
In your own REPL begin with:
    import ast, json
    request = json.loads(context.split("\nREQUEST_JSON:\n", 1)[1])
    best_source = request["candidate_source"]
Inspect the reference/contract/last_feedback in request, repair the full source,
syntax-check with ast.parse, and call compile_candidate(best_source) yourself.
Use the shared resources and live search_docs/read_doc for a specific API blocker.
Keep the returned status/detail/error_type/traceback/stdout/stderr/launcher_stderr
when present in checks; a status of compiled is only a forward/synchronize smoke,
not numerical correctness, speed or proof of CuTe launch. Do not invent evidence.
Do not spawn another child. Return JSON, not Markdown, by setting:

Here checks is a list of actual feedback dictionaries; changes and remaining_risks

REQUEST_JSON:
